unpushed

Overview of unpushed commits across many git checkouts.

GitUI and friends work on one repository at a time. unpushed sits a level above: point it at the directory that holds your checkouts and it shows, for all of them at once, what is not pushed yet and what is dirty — and lets you push from the list.

2 need work · 44 clean · 0 failed   (47 repos, 2 visible)
/home/you/src

      Repo          Branch         Upstream     Main
   ↑  backend-api   feature/login  no upstream  ↑3
   ⚠  shared-lib    main           —            on default  ⚠ 2 modified

j/k select · Enter gitui · p push · Space mark · A visible · P marked · f/F fetch · …

Only one level is searched. Point it at the directory that holds the checkouts, not at the root of a tree.

Install

Homebrew — macOS

brew tap pie-ai/unpushed
brew install unpushed

Or in a single command, without tapping first:

brew install pie-ai/unpushed/unpushed

Upgrading and removing:

brew upgrade unpushed
brew uninstall unpushed
brew untap pie-ai/unpushed

In a Brewfile, for machine setup:

tap "pie-ai/unpushed"
brew "unpushed"

The formula installs a prebuilt binary, so there is nothing to compile and no Rust toolchain needed. Apple silicon and Intel are both covered. gitui is optional — the g key opens it when present.

apt — Debian and Ubuntu

curl -fsSL https://pie-ai.github.io/unpushed/key.gpg \
  | sudo tee /etc/apt/keyrings/unpushed.asc > /dev/null

echo "deb [signed-by=/etc/apt/keyrings/unpushed.asc] \
  https://pie-ai.github.io/unpushed stable main" \
  | sudo tee /etc/apt/sources.list.d/unpushed.list

sudo apt update && sudo apt install unpushed

Packages are built for amd64, arm64 and armhf, and are statically linked, so they carry no dependency on a system libgit2. Tested on Debian bookworm and trixie.

Raspberry Pi: a 64-bit OS installs the arm64 package, a 32-bit OS the armhf one — apt picks the right one. The armhf build targets ARMv7, so it covers the Pi 2 and later. The Pi 1 and Zero are ARMv6 and are not supported.

Prebuilt binary — any Linux or macOS

curl -fsSL https://github.com/pie-ai/unpushed/releases/latest/download/unpushed-x86_64-unknown-linux-musl.tar.gz \
  | tar xz
sudo install -m 755 unpushed-x86_64-unknown-linux-musl/unpushed /usr/local/bin/

Every archive carries the binary, a man page, shell completions for bash, zsh and fish, and the licenses. Checksums are published as SHA256SUMS with each release.

Cargo

cargo install unpushed

Or straight from the repository, for an unreleased state:

cargo install --git https://github.com/pie-ai/unpushed

Builds from source; needs Rust 1.88 or newer. The other routes install a prebuilt binary and need nothing.

Using it

unpushed                  # current directory
unpushed ~/src/checkouts  # explicit directory
unpushed -T               # plain table instead of the interface
KeyAction
j/k, ↑/↓move the selection
Enter (or g)open GitUI in the repository
Spacemark a row
ppush the selected repository
A / Ppush every visible / marked repository
f / Ffetch selected / all visible
/filter by branch or name
ashow all repositories
qquit

The list keeps itself current: every few seconds every repository is read again, so a file you change in another window shows up on its own. Background refreshes show no spinner and lock nothing — a row must never be busy at the moment you reach for a key. --refresh 0 turns it off.

While a repository is being fetched, read or pushed, its row shows a spinner and says what it is doing, and every key that would touch that repository is refused until it settles.

Push fetches the repository first, refuses when the branch is behind origin/<branch> rather than forcing, and uses an explicit refspec so a wrong upstream cannot send commits to the wrong remote branch.
